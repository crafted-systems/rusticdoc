# Security

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately with [Report a vulnerability](https://github.com/crafted-systems/rusticdoc/security/advisories/new), which is also under the repository's Security tab. Only the maintainers can read the report.

Tell us what you found, the version or image tag you ran, and the steps or a small file that reproduces it. We'll confirm we have the report, tell you what we find, and credit you in the advisory if you'd like.

## Supported versions

Fixes go into the latest release. rusticdoc follows [ZeroVer](https://0ver.org), so older 0.x releases don't get patches. Upgrade to the newest version to pick up a fix.

## Running it safely

The documentation covers how to deploy rusticdoc safely in [Security](https://rusticdoc.com/docs/operate/security/).
